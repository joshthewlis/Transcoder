Settings

Execution gate, automation, and app-level controls.

Worker Run Mode

This is the server-wide execution gate. Use PlanAndReview to inspect plans safely. Use Run staged work to allow cleanup/transcode jobs to run to the staging area. Libraries still decide whether cleanup/transcode jobs can be generated.

Job Generation Automation

These switches decide whether approved plans create queued jobs automatically. The worker run mode controls whether those queued jobs are allowed to execute. Each library also has its own cleanup/transcode generation switches.

Active Hours

Controls when long staged work can start. With the defaults, Cleanup/Transcode leases can start from 08:30 until 01:30, leaving a 30 minute guard before the NAS shuts down at 02:00.
